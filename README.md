# skills

Agent skills for Claude Code, Codex and other agents that read `SKILL.md` files.

| Skill | What it does |
|-------|--------------|
| [braintrust-cli](braintrust-cli/SKILL.md) | Use the Braintrust CLI (`bt`) for logs, traces, SQL, experiments, datasets, prompts, scorers and evals |

## Install

```bash
npx skills add joshm1/skills --skill braintrust-cli
```

Or copy a skill's directory into `~/.claude/skills/` (Claude Code) or `~/.agents/skills/`.
